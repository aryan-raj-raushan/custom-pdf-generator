# 📄 Custom PDF Question Paper Generator

A powerful and customizable PDF Question Paper Generator built with **Next.js**. This application allows users to create professional question papers either manually or by importing content from documents. The system automatically formats, arranges, and generates print-ready PDF files based on customizable layouts.

---

## ✨ Features

- 📝 Create question papers manually
- 📂 Import questions directly from documents
- 🤖 Automatic question formatting and arrangement
- 📄 Generate professional PDF question papers
- 🎨 Fully customizable layouts and styling
- 🔢 Automatic question numbering
- 📚 Support for multiple question sections
- ⚡ Real-time preview before PDF generation
- 📥 Export high-quality PDF files
- 📱 Responsive and user-friendly interface

---

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** React
- **PDF Generation:** Custom PDF Engine
- **Package Manager:** npm

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js (v18 or above)
- npm / yarn / pnpm / bun

---

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project:

```bash
cd custom-pdf-generator
```

Install dependencies:

```bash
npm install
```

or

```bash
yarn install
```

or

```bash
pnpm install
```

---

## Running the Development Server

Start the development server:

```bash
npm run dev
```

or

```bash
yarn dev
```

or

```bash
pnpm dev
```

Open your browser and visit:

```
http://localhost:3000
```

The application will automatically reload when you make changes.

## How It Works

### Manual Question Creation

- Add questions individually
- Organize into sections
- Configure marks and numbering
- Customize formatting

### Document Import

- Upload supported documents
- Automatically extract questions
- Arrange content into the selected template
- Edit before generating the final PDF

### PDF Generation

The generator automatically:

- Formats questions
- Applies consistent spacing
- Maintains proper alignment
- Adds numbering
- Preserves layout
- Generates a print-ready PDF
